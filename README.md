# las-savoy-dorm-store
A self-contained point-of-sale and inventory system for a boarding school dorm store. Built with Next.js + Google OAuth + Google Sheets. No external student-data databases.
1. Project Overview
A web-based point-of-sale app for a boarding school dorm store. Students log in with their school Gmail, browse available items, add them to a cart, and submit their purchase. Transactions are written directly to a Google Sheets workbook for analytics, P&L tracking, and daily reporting — with no third-party database involved.
Shopkeepers have an admin panel to manage items, prices, stock levels, and view reports.
